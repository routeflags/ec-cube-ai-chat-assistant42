### プラグイン仕様（https://doc4.ec-cube.net/plugin_spec）

`composer.json` に関する定義の抜粋（オーナーズストア審査の根拠）：

- `description`: **プラグイン名称**（説明文ではない）
  - 記載例: `"description": "商品レビュー管理プラグイン"`
  - 管理画面のプラグイン一覧ではこの値がプラグイン名称として表示される
- `require`: EC-CUBE 4.2系以降は `"ec-cube/plugin-installer": "^2.0"` を常に記述する
- パッケージング: `tar.gz` 形式、フォルダごと圧縮しない、`.git` や `.DS_Store` を含めない

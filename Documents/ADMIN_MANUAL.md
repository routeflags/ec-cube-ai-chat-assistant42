## 1. 概要

AI チャットアシスタントは、EC サイトの訪問者に AI が商品情報や FAQ を自動回答するプラグインです。OpenAI / Anthropic / Google Gemini の 3 プロバイダに対応しています。

### 管理画面メニュー

```
設定
└── AI チャットアシスタント
    ├── ダッシュボード
    ├── プラグイン設定
    ├── チャット履歴
    ├── 統計・レポート
    ├── ナレッジ管理
    ├── シナリオ管理
    ├── アクセスルール
    ├── デザイン設定
    └── 通知ルール
```

### 必須設定（初回セットアップ）

1. **プラグイン設定** で API キーとプロバイダを選択
2. **チャットを有効にする** を ON
3. フロントのチャットウィジェットを確認

## 2. ダッシュボード

**URL**: `/<admin_route>/ai-chat-assistant/dashboard`

AI チャットの運用状況を一覧表示します。

### 表示内容

| セクション | 内容 | 更新頻度 |
|-----------|------|---------|
| KPI カード | 総会話数・解決率・エラー率・平均応答時間 | リアルタイム |
| プロバイダ別使用量 | OpenAI / Anthropic / Gemini の件数・構成比 | リアルタイム |
| 時間帯別リクエスト分布 | 0〜23時のバーチャート | リアルタイム |
| エラー内訳 | エラータイプ別・最新メッセージ | リアルタイム |
| 未対応メール返信 | メール返信依頼のうち未対応件数 | リアルタイム |

### KPI の定義

| KPI | 計算方法 | 説明 |
|-----|---------|------|
| 総会話数 | 過去30日のチャット総数 | `COUNT(log.id)` |
| 解決率 | `resolved / total × 100` | ユーザーが「解決した」と評価した割合 |
| エラー率 | `errors / total × 100` | AI 応答でエラーが発生した割合 |
| 平均応答時間 | `AVG(response_time_ms)` | AI 応答にかかった平均時間（ミリ秒） |

## 3. プラグイン設定

**URL**: `/<admin_route>/ai-chat-assistant/settings`

AI チャットの基本設定を行います。

### 設定項目

| 項目 | 説明 | デフォルト値 |
|------|------|------------|
| チャット有効/無効 | フロントのチャットウィジェットを表示するかどうか | 無効 |
| デフォルトプロバイダ | OpenAI / Anthropic / Google Gemini | OpenAI |
| デフォルトモデル | 使用する AI モデル | gpt-4o |
| 最大トークン数 | AI 応答の最大文字数 | 4096 |
| レート制限 | 1分間あたりのリクエスト上限 | 30 |
| システムプロンプト | AI の振る舞いを定義するテキスト | （空） |

### API キー設定

| プロバイダ | 入力欄 | キー形式 |
|-----------|--------|---------|
| OpenAI | OpenAI API Key | `sk-...` |
| Anthropic | Anthropic API Key | `sk-ant-...` |
| Google Gemini | Google Gemini API Key | `AIza...` |

**注意事項**:
- API キーは `type="password"` で入力し、保存後に値は再表示されません（`sk-****...abcd` のマスク表示）
- キーを変更したい場合は新しいキーを入力してください。空欄にすると既存のキーが維持されます
- 保存時に `AES-256-GCM`（`APP_SECRET` 由来）で暗号化して DB に保存します。`APP_SECRET` 変更時は再登録が必要です
- システムプロンプトは空の場合、デフォルトのプロンプトが使用されます

### 外部送信に関する事前確認（セキュリティガイドライン §2-3 準拠）

> **重要:** 本プラグインは、チャット入力・商品情報・ナレッジ・会話履歴のうち必要なもののみを、設定した外部AIプロバイダ（`api.openai.com` / `api.anthropic.com` / `generativelanguage.googleapis.com`）へ送信します。
> 顧客の氏名・住所・電話番号等の個人情報は送信対象外です。送信に同意の上で APIキーを登録してください。
> 顧客向けプライバシーポリシーに「チャット内容を外部AIサービスへ送信すること」を追記することを推奨します。設定画面にも同内容の注意表示を行っています。

#### 通信先一覧

| 用途 | 通信先 | プロトコル | 備考 |
|------|--------|-----------|------|
| AI応答生成 | `api.openai.com` / `api.anthropic.com` / `generativelanguage.googleapis.com` | HTTPS (TLS 1.2+) | 選択したプロバイダのみ。ペイロードは `messages` + `tools` の最小限 |
| モデル定義同期 | `routeflags.com/dist/ec_chat/ai_models.json` | HTTPS | 1日1回、ETag/Last-Modified による条件付き取得。失敗時は同梱 `Resource/config/ai_models.json` にフォールバック |
| デザイン同期 | `routeflags.com/dist/ec_chat/design_settings.json` | HTTPS | 同上。`license_*` のみリモート正本、`widget_*` はローカル保持 |

#### ログ

- 外部通信は `monolog`（`var/log/*.log`）に `日時・リクエスト元・IP` を含めて記録します（ガイドライン §2-3 ログ徹底）
- 失敗時は `warning` / 成功時は `info` レベルで `[AiChatAssistant42]` プレフィクス付きで記録

### システムプロンプトの書き方例

```
あなたは当ショップの商品アドバイザーです。
商品の成分・効果・使い方について専門的な知識で回答してください。
回答は簡潔かつ丁寧に。在庫状況や価格については正確に伝えてください。
```

## 6. ナレッジ管理

**URL**: `/<admin_route>/ai-chat-assistant/knowledge`

FAQ や商品情報を AI が参照するナレッジベースを管理します。

### ナレッジとは

AI チャットへの回答に含める情報を事前に登録する機能です。登録されたナレッジは、AI のシステムプロンプトに自動的に組み込まれます。

### ナレッジ登録

| 項目 | 説明 | 必須 |
|------|------|:----:|
| タイトル | ナレッジの見出し | ○ |
| 本文 | 回答に含める詳細情報 | ○ |
| カテゴリ | 分類名（例: 「返品・交換」「配送」「商品情報」） | |
| ステータス | 有効 / 無効 | |
| 表示順 | 数値が小さいほど優先 | |

### ナレッジの効果

- 登録されたナレッジは AI のシステムプロンプト末尾に追加される
- タイトルと本文が「【カテゴリ】タイトル: 本文」形式で組み込まれる
- 最大50件まで有効なナレッジが参照される

### ナレッジの書き方のコツ

| 良い例 | 駄目な例 |
|--------|---------|
| 「返品は商品到着後7日以内、未開封品に限り可能」 | 「返品について」 |
| 「送料は全国一律500円（税込）。5,000円以上で送料無料」 | 「送料について」 |
| 「営業時間は10時〜18時です。土日祝日も営業」 | 「営業時間」 |

## 7. シナリオ管理

**URL**: `/<admin_route>/ai-chat-assistant/scenario`

特定のキーワードに対する定型応答を事前設定します。

### シナリオとは

ユーザーの入力がキーワードに一致した場合、AI を呼ばずに定型応答を即座に返す機能です。AI の応答よりも高速で、コストゼロで応答できます。

### シナリオ登録

| 項目 | 説明 | 必須 |
|------|------|:----:|
| トリガーキーワード | マッチング対象のキーワード | ○ |
| マッチタイプ | 完全一致 / 部分一致 / 正規表現 | ○ |
| 応答テキスト | 返す定型応答 | ○ |
| 応答タイプ | テキスト / 商品一覧 / URL | ○ |
| 優先度 | 数値が大きいほど優先（デフォルト: 0） | |
| ステータス | 有効 / 無効 | |

### マッチタイプの使い分け

| タイプ | 説明 | 使用例 |
|--------|------|--------|
| 完全一致 (exact) | 入力がキーワードと完全に一致する場合のみマッチ | 「返品」→「返品」のみ |
| 部分一致 (contains) | 入力にキーワードが含まれる場合にマッチ | 「返品」→「返品の方法を教えて」にも |
| 正規表現 (regex) | 正規表現パターンでマッチ | `/^(返品\|キャンセル)/` → 「返品したい」にも |

### 優先度の使い方

複数のシナリオがマッチした場合、**priority が高い（数値が大きい）もの**が採用されます。

例:
- priority=10 のシナリオ「返品」
- priority=5 のシナリオ「返品」
- → priority=10 の方が優先される

## 11. FAQ・トラブルシューティング

### よくある質問

**Q: チャットウィジェットがフロントに表示されない**

A: 以下の点を確認してください。
1. プラグイン設定で「チャット有効/無効」が「有効」になっているか
2. API キーが正しく設定されているか
3. ブラウザのコンソールにエラーがないか

**Q: AI が回答しない / エラーになる**

A: 以下の点を確認してください。
1. API キーが有効期限内で、残量があるか
2. 選択中のプロバイダの API キーが設定されているか
3. レート制限に達していないか（デフォルト: 30回/分）

**Q: 複数ターンの会話で文脈が失われる**

A: セッション ID が同一であることを確認してください。ブラウザを閉じるとセッション ID が変更されます。

**Q: ナレッジが AI の回答に反映されない**

A: 以下の点を確認してください。
1. ナレッジのステータスが「有効」になっているか
2. ナレッジが50件以内に収まっているか（上限あり）

**Q: デザイン設定がフロントに反映されない**

A: ブラウザのキャッシュをクリアしてから、フロントページを再読み込みしてください。

### 個人情報の保持ポリシー（I-30 対応）

- `plg_ai_chat_assistant_log.email_reply_address` にメールアドレスを保存します（メール返信依頼機能のため）。
- **保持期間:** 返信対応後 **30日** を目安に削除することを推奨します。
- **削除方法:** 管理画面 `チャット履歴` の削除、または `bin/console doctrine:query:dql "DELETE FROM Plugin\AiChatAssistant42\Entity\ChatLog l WHERE l.email_replied_at < :d" --set-d="2026-08-03"` 等で一括削除できます。
- ログ出力時はメールアドレスをマスク（`a***@example.com`）して記録し、平文は出力しません。
- 上記以外の個人情報（氏名・住所・電話番号等）は本プラグインのDBに保存しません（ガイドライン §2-3 個人情報の保持制限 準拠）。

# ChatGPT / Claude との接続手順（自店で試す）

AI Chat Assistant の MCP サーバー（`/mcp`）を、ChatGPT または Claude に接続して自店の商品を質問できるようにする手順。所要 5〜10 分。

- 対象: プラグイン 1.1.3 以降
- 前提: 店舗が **HTTPS** で公開されていること（自己署名証明書不可）
- UI の名前は変更されやすい。見つからない場合は画面内の検索で「MCP」「コネクタ」「プラグイン」を探す

---

## 0. 先に接続可否を確かめる

ブラウザで次を開き、`tools` が 7 件返ればサーバー側は準備できている。

```text
https://<店舗ドメイン>/.well-known/mcp.json
```

開けない・404 の場合は先に [トラブルシューティング](#4-うまくいかないとき) を見る。

---

## 1. ChatGPT に接続する

### 1.1 必要なもの

- ChatGPT の **Plus / Pro / Business / Enterprise / Edu**（無料プランは不可）
- Business / Enterprise / Edu の場合: 管理者がワークスペース設定で「MCP を使ったプラグイン作成」を許可していること

### 1.2 手順

1. ChatGPT（Web）にログインする
2. 設定 → **アプリとコネクター**（または「コネクター」）→ 下部の **詳細設定** を開く
3. **開発者モード** を ON にする（警告が出たら内容を確認して続行）
4. **プラグイン**（旧「コネクター」）→ **＋** → **カスタム MCP サーバーを追加**
5. 入力する
   - 名前: 店舗名（例: ○○商店 AI アシスタント）
   - 説明: 任意（例: 「商品検索と在庫確認」）
   - サーバー URL: `https://<店舗ドメイン>/mcp`
   - 認証: **なし**（現行のプラグインは読み取り専用で認証を持たない）
6. リスク警告を確認して **作成** し、そのプラグインを **インストール** する
7. 会話入力欄で `@` を押し、作成したプラグインを選んでから質問する

### 1.3 動作確認の例

```text
この店の初心者向けの商品を探して
```

```text
一番安いのはどれ？在庫はある？
```

---

## 2. Claude に接続する

1. Claude（Web / Desktop）にログインする
2. 設定 → **コネクター** → **カスタムコネクターを追加**
3. 名前と URL（`https://<店舗ドメイン>/mcp`）を入力して接続する
4. 会話でツールを使うよう依頼する

---

## 3. 接続後に見えるはずのもの

| 項目 | 期待値 |
| --- | --- |
| ツール数 | 7 |
| ツール名 | `search_products` / `get_product_detail` / `get_stock` / `get_categories` / `get_category_products` / `get_tags` / `search_by_tag` |
| 安全注釈 | 7 ツールすべて読み取り専用（`readOnlyHint: true`） |
| 価格 | 税抜表示 |
| 商品 URL | 店舗の商品詳細ページの絶対 URL |

---

## 4. うまくいかないとき

| 症状 | 原因の候補 | 対処 |
| --- | --- | --- |
| 「接続できません」 | 店舗が HTTP / ベーシック認証 / WAF で保護されている | HTTPS で公開し、`/mcp` と `/.well-known/mcp.json` を認証不要で通す |
| 404 | EC-CUBE のルーティングに載っていない | プラグインを有効化し、キャッシュを削除する |
| 接続できるがツールが出ない | プロトコルバージョンの不一致 | 1.1.3 以降に更新する（要求値の交渉に対応） |
| 429 が頻発する | レート制限はクライアント IP 単位（120 req/min）で、ChatGPT は共有 IP から来る | 利用が少ない店舗では通常起きない。頻発する場合はトークン単位の制限への変更が必要（計画に記載） |
| 商品 URL が `https://www.example.com/...` になる | 店舗の URL が正しく取得できていない | `framework.trusted_proxies` を設定する（`Documents/LOCAL_VERIFICATION.md` のプロキシ節） |
| 価格が税込で案内される | EC-CUBE の `price02` は税抜保存 | 仕様。ツール説明にも税抜と明記済み |

---

## 5. セキュリティ上の注意

- この接続は **読み取り専用**。注文・カート・顧客情報には触れない。
- エンドポイントは公開されている。誰でも店舗の商品カタログを読める状態になる（店頭に並んでいる情報と同じ）。
- 接続はいつでも解除できる。解除後は相手側からツールは見えない。
- 注文機能を追加する段階では認証（OAuth）が必須になる。詳細は [ChatGPT プラグイン登録計画](CHATGPT_PLUGIN_PLAN.md) の第 7 章。

---

## 6. 解除方法

- ChatGPT: 設定 → アプリとコネクター → 対象のプラグイン → 削除
- Claude: 設定 → コネクター → 対象のコネクター → 切断
